# Replicate homepage interactions, not GSAP identity

The first delivery mirrors the GSAP homepage's interaction and compositional structure using neutral placeholders, while excluding GSAP's brand, copy and assets. It deliberately covers only the homepage so Dancer Method can validate a commercial narrative before adding any secondary routes or Ro-specific final media. Pinned horizontal scenes are desktop-only; mobile and reduced-motion users receive equivalent vertical, native-scroll content.
